Краткая инструкция для IPTV-плеера Televizo (Для Smart TV)
ABUBAKR
1. Установка:
Загрузите "Televizo - IPTV player" из Google Play или APK с televizo.net (https://televizo.net/).
![photo_2025-10-18_13-47-16](https://github.com/user-attachments/assets/811106f8-4bb1-4f82-96b9-3cf91762302c)

2. Плейлиста: 
  - Перейдите в "Новые M3U плейлист"
![photo_2025-10-18_13-56-33](https://github.com/user-attachments/assets/2be1c961-f980-495d-bd05-744687c852b9)

- Перейдите в "Создать плейлист"
![photo_2025-10-18_13-58-17](https://github.com/user-attachments/assets/8fa4e196-864a-4342-8358-81a13b01d9d4)


3.  Добавление плейлиста:
1.Добавить имя плейера (любой).
2.Вставьте URL (http://iptv.fibernet.uz/IPTV.m3u).
3.Нажмите галочку (в правом верхнем углу).
![photo_2025-10-18_14-01-13](https://github.com/user-attachments/assets/bb28b26a-d595-44be-ba98-ec3e8b828a33)


5. Просмотр:
 - Откройте "Все каналы" (151 канал на фото).
 - Выберите канал (например, "Первый канал HD") и нажмите >.
 ![photo_2025-10-18_14-13-37](https://github.com/user-attachments/assets/5ec7aa16-20b7-4805-8182-dae80c131e0c)
